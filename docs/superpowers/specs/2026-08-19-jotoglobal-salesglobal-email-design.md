# JOTO Global 公开销售邮箱更新设计

## 目标

将 JOTO Global 网站公开销售邮箱及网站表单通知收件地址统一更新为 `salesglobal@jototech.cn`，保持三语言页面、邮件链接、来源标签和结构化数据一致，并部署到线上网站。

## 范围

本次更新覆盖：

- 中文、英文、波斯语首页和所有页面的页脚邮箱；
- 联系我们页面的销售联系方式；
- 解决方案、商城、博客及其他运行时页面中的销售邮件入口；
- 所有 `mailto:` 链接的真实收件地址；
- 联系表单失败时展示的邮件回退入口；
- 网站的 Organization JSON-LD 邮箱字段；
- JOTO Global 表单通知的专属后端收件地址。

本次不修改页面布局、文案、来源标签格式、表单字段、其他站点的邮件路由，也不触碰工作区中尚未完成的 Cisco 认证轮播修改。

## 实现方案

前端继续使用现有 `assets/jotoglobal-lead-routing.js` 作为公开邮箱的唯一常量来源，将 `SALES_EMAIL` 更新为 `salesglobal@jototech.cn`。同步更新联系表单脚本及主运行时包中仍存在的旧地址，并提高主运行时和邮件路由资产版本参数，强制浏览器与边缘节点加载新内容。

后端仅修改 JOTO Global 专属联系表单路由的收件地址；其他站点沿用各自既有配置。来源信息、邮件主题格式、Reply-To 和数据库记录方式保持不变。

## 验证

本地验证要求：

- 运行时前端资源不再包含 `sales@jotoglobal.com` 和 `sales@jototech.cn`；
- 公开邮箱文本与所有 `mailto:` 目标均为 `salesglobal@jototech.cn`；
- JOTO Global 表单通知目标为 `salesglobal@jototech.cn`；
- 其他站点的收件路由不变；
- 现有首页、联系表单、商城、排版和站点规则测试继续通过。

线上验证至少检查三语言首页、三语言联系我们页面、一个解决方案页面和一个商城产品页面，确认新邮箱可见、链接正确、旧邮箱为零，并检查表单请求仍携带来源信息。

## 发布与回滚

沿用现有不可变发布目录：从当前线上版本复制出新目录，覆盖本次已验证的前端和后端文件，验证 Nginx 与健康检查后切换 `current` 软链接。若线上复核失败，立即将软链接切回上一个发布目录，并恢复后端备份。
