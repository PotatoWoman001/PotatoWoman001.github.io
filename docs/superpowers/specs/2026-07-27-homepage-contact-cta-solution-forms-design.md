# 首页联系 CTA 与 Solution 详情页表单设计

## 1. 目标

在不替换首页现有“联系 JOTO”内容板块的前提下，为三语言首页 Hero 增加第二个标准 CTA，并为所有 Solution 分类页和厂商详情页提供可直接提交的本地化联系表单。

本设计已经通过中文正式页面预览确认：

- 首页“联系我们”与“查看解决方案”并列显示；
- Solution 详情页底部联系区域使用完整表单；
- 中文标题采用“说说您的需求，我们一起找到解决方案。”；
- 不显示“安全咨询”或提交授权说明。

## 2. 页面范围

- 英文、中文、波斯语首页；
- 五类 Solution 分类页；
- 二十个 Solution 厂商详情页；
- 上述详情页的三种语言版本。

页头、页脚和首页原“联系 JOTO”板块不在本次修改范围内。

## 3. 首页 Hero CTA

“联系我们”放在现有“查看解决方案”按钮旁边：

- 桌面和平板保持同一水平行；
- 两个按钮均为标准 CTA，尺寸 `280 × 48px`；
- 按钮内容保持单行并在按钮内部居中；
- 按钮组从现有 Hero 正文起始线开始排列；
- 手机端空间不足时纵向排列，每个按钮宽度 `100%`、最大宽度 `280px`；
- 英文链接到 `/contact`，中文链接到 `/zh/contact`，波斯语链接到 `/fa/contact`；
- 波斯语按钮顺序和图标方向遵循 RTL 镜像规则。

## 4. Solution 详情页表单

分类页和厂商详情页底部原联系 CTA 升级为表单。绿色背景和页面整体视觉保持不变，内容采用标题与深色表单组合：

- 姓名，必填；
- 公司，必填；
- 工作邮箱，必填；
- 电话 / 微信，选填；
- 项目问题描述，必填；
- 隐藏 honeypot 字段；
- 提交按钮。

表单提交到现有 `/api/contact`，JSON 字段保持与 Contact 页面一致：

```json
{
  "name": "",
  "company": "",
  "email": "",
  "phoneOrWechat": "",
  "message": "",
  "website": ""
}
```

表单提供本地化的提交中、成功和失败状态。失败状态包含 `sales@jototech.cn` 邮件回退入口。

## 5. 文案

中文联系区：

- 标题：`说说您的需求，我们一起找到解决方案。`
- 说明：`分享地点、重点与时间计划，JOTO 将协助梳理切实可行的下一步。`
- 表单标题：`发送您的项目需求`
- 提交按钮：`提交项目需求`

英文和波斯语使用自然、本地化的等义表达。所有按钮文案必须保持单行。

## 6. 按钮规范

依据 `docs/site-modification-rules.md`：

- 首页两个 Hero CTA 均为标准 CTA：`280 × 48px`；
- 表单提交按钮为标准 CTA：`280 × 48px`；
- 页头 Contact 等短入口继续使用紧凑按钮：`96 × 36px`；
- 本任务不改变全站两级按钮系统。

表单提交按钮位于表单底部正中间，不显示“安全咨询”，也不显示“提交即表示……”说明。

## 7. 技术方案

仓库只有编译后的静态站点，因此使用独立渐进增强资源：

- `assets/contact-form-sections.js`：识别 URL 语言与页面类型，插入首页 CTA 或详情页表单；
- `assets/contact-form-sections.css`：实现按钮组、表单布局、RTL 和响应式样式；
- 首页和 Solution 路由 HTML 引入以上资源；
- 其他页面不引入，Contact 页面继续使用原 React 表单。

增强脚本使用 `MutationObserver` 等待 React 内容出现。脚本失败时，原首页 CTA 和详情页联系链接仍然可用。

## 8. 无障碍与响应式

- 表单字段使用唯一的 `id`、`label` 和原生表单控件；
- 必填字段使用原生 `required`；
- 状态区域使用 `aria-live="polite"`；
- honeypot 不进入键盘导航；
- `#contact` 深链接在表单渲染后正确定位；
- 波斯语使用 RTL 排列，邮箱输入保持 LTR；
- 390px、768px、1440px 视口不产生横向溢出；
- 减少动态效果模式下不使用非必要过渡。

## 9. 验收标准

1. 三语言首页均出现两个标准 CTA，桌面同行、手机纵向。
2. 两个首页 CTA 和表单提交按钮均为 `280 × 48px`。
3. 所有三语言 Solution 分类页和厂商详情页显示表单。
4. 中文页面没有“安全咨询”和授权说明。
5. 表单按钮文字在三种语言中均保持单行。
6. 提交请求指向 `/api/contact`，字段与 Contact 页面一致。
7. 英文、中文、波斯语及 RTL 页面无横向溢出和控制台错误。
