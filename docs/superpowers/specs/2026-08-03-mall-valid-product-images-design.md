# Mall 有效产品图片统一过滤设计

**日期：** 2026-08-03

**状态：** 已实施并通过三语言响应式验证

## 1. 目标

统一过滤 Mall 产品数据中的空路径、已知占位图片和浏览器加载失败图片，避免空白图或来源站占位图出现在产品列表、详情主图、缩略图、分享元数据及结构化数据中。

## 2. 问题现状

- `mall-data-client.js` 目前只用两个已知文件名判断产品是否至少有一张有效图片。
- `mall-product-page.js` 直接使用原始 `product.images`，因此同一产品中的 Magento 灰色占位图仍会进入缩略图库。
- 分享图与 JSON-LD 也直接读取原始图片数组，可能继续暴露占位图片。
- 图片请求失败时，当前图库不会自动移除失败项或切换到下一张有效图片。

## 3. 统一图片接口

在 `mall-data-client.js` 中新增并导出 `validProductImages(product)`：

- 只接受非空字符串路径。
- 去除查询参数与片段后，按文件名过滤已知占位图集合。
- 对重复路径去重，同时保留原始顺序。
- `hasProductImage(product)` 改为判断 `validProductImages(product).length > 0`。

已确认的 Magento 灰色占位图文件名加入占位集合：

`2637f446bc6640220c9b726c624f2156836bb7a67b754c098f7fda5f126c7fcc.jpg`

## 4. 使用范围

- 产品目录继续只展示至少有一张有效图片的产品。
- 产品卡片使用过滤后的第一张有效图片。
- 产品详情主图和缩略图只使用过滤后的图片数组。
- Open Graph 图片和 JSON-LD `image` 使用相同的过滤结果。
- 不修改抓取快照文件，避免下一次数据同步重新引入问题。

## 5. 浏览器失败处理

- 主图加载失败时，从图库删除该路径并切换到下一张有效图片。
- 缩略图加载失败时，移除对应缩略图按钮。
- 如果所有图片均加载失败，图库显示现有中性占位容器，但不显示空白缩略图。
- 产品目录仍依赖数据层的已知占位过滤；运行时加载失败不会改变产品数据或分页总数。

## 6. 验证标准

- 单元验证覆盖空数组、空字符串、重复图片、已知占位图和有效图混合数组。
- AR0B0037BA 详情页不再显示 Magento 灰色占位缩略图。
- 详情主图、缩略图、Open Graph 与 JSON-LD 不包含已知占位图片。
- 产品列表仍排除完全无有效图片的产品。
- 英文、中文、波斯语的目录与详情页均无图片加载错误、控制台错误或横向溢出。

## 7. 非目标

- 不用图像识别扫描所有产品图片内容。
- 不修改来源抓取器或历史产品 JSON。
- 不删除有效的不同角度产品图片。
- 不改变产品分页、筛选或布局密度。
