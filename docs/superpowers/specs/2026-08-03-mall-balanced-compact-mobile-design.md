# Mall 手机端均衡紧凑版设计

**日期：** 2026-08-03

**状态：** 已实施并通过三语言响应式验证

**适用范围：** 英文、简体中文、波斯语 Mall 产品网格、列表与产品详情页

## 1. 目标

在不减少产品信息和可点击提示的前提下，提高手机端产品浏览密度，并让产品详情页与 Mall 首页使用同一套浅绿色网格背景、白色内容面板和页面边距。

## 2. 已确认的视觉方向

- 采用“均衡紧凑版”，不使用极限压缩方案。
- 手机端产品网格固定为两列，包括宽度小于 `420px` 的设备。
- 每张网格卡继续显示品牌、完整型号和“查看详情”。
- 产品图片继续使用白色背景和 `object-fit: contain`，不裁切设备图。
- 手机端列表继续展示与网格相同的当前筛选结果，每页仍为 `24` 件；行高压缩到约 `68px`。
- 产品详情页左右保留 `14–16px` 页面边距，外层使用浅绿色技术网格背景，正文进入白色圆角内容面板。
- 详情页缩小主图、缩略图、标题、元数据与段落间距。
- 详情页“联系我们”保留在正常正文流中；不再使用遮挡正文的手机端粘性大按钮。

## 3. 手机网格

- 断点：`<= 767px` 使用两列；`<= 419px` 不再降为一列。
- 列间距和行间距目标为 `8px`。
- 图片区使用更扁的横向比例和更小内边距。
- 卡片文案区缩小到约 `8px` 内边距。
- 品牌使用小号大写标签；型号根据长度使用现有 `small/xsmall` 类缩放，但保持单行完整显示。
- 次要产品类型在手机网格隐藏，避免重复信息拉高卡片。
- “查看详情”保持绿色、可见并位于卡片底部。

## 4. 手机列表

- 行高目标 `68px`，图片列约 `72px`，图片区高度约 `66px`。
- 文案区只保留品牌、型号和“查看详情”，隐藏产品类型。
- 型号单行显示；超长型号沿用已有长度分级字号，不换行。
- 列表项之间使用约 `6px` 间距。

## 5. 产品详情页

- 页面背景复用 Mall 首页的浅绿色网格与轻微绿色光晕。
- 白色正文面板使用 `18px` 圆角、细边框和轻阴影。
- 手机端正文面板与视口左右间距为 `14px`。
- 面包屑缩小并压缩底部间距。
- 主图使用约 `16:10` 比例；缩略图缩小到约 `64 × 50px`。
- 产品标题目标 `26px / 1.2`，避免当前超大字号造成大量断行。
- 摘要、元数据、详情分段统一缩短纵向间距。
- 正文中的“联系我们”按钮保留，手机端可使用面板宽度；重复的粘性按钮隐藏。

## 6. 响应式与无障碍约束

- 桌面端六列、平板端三列逻辑不变。
- 英文、中文和波斯语使用同一布局密度；波斯语继续遵循 RTL。
- 页面不得产生横向溢出。
- 每张产品卡的链接、`aria-label`、完整型号提示和键盘焦点能力保持不变。
- 图片加载失败过滤、分页、筛选、产品数量和详情数据不在本次修改范围内。

## 7. 验证标准

- `390 × 844` 下网格为两列，一屏能看到至少两行产品卡片的主要内容。
- 手机网格每张卡可见品牌、完整型号和“查看详情”。
- 手机列表单行高度不超过约 `70px`，与网格使用相同的 `24` 件产品集合。
- 手机详情面板左右边距至少 `14px`，白色圆角面板可见，主图高度明显下降。
- 手机详情标题不大于 `26px`，粘性按钮不遮挡正文，正文“联系我们”可见。
- 英文、中文、波斯语在桌面、平板和手机视口无横向溢出，控制台无错误或警告。

## 8. 非目标

- 不修改产品抓取数据、分类数量或分页大小。
- 不重写 Mall 页面 JavaScript 架构。
- 不改变桌面端网格密度。
- 不改变公开语言入口策略。
- 本设计文档本身不代表已经发布线上版本。
