# Mall 紧凑分类标签栏设计

**日期：** 2026-07-29  
**状态：** 已确认视觉方向，待实施  
**适用范围：** 英文、中文、波斯语 Mall 首页

## 1. 背景

当前 Mall 首页“产品分类”区域采用三列大卡片。单张卡片最小高度为
144px，分类板块上下留白最高达到 104px，再叠加标题与标题下方间距，
桌面端整体约占 380px 高度。分类数量较少时，这种布局产生大量无效空白，
使用户需要额外滚动才能进入最近收录的产品区域。

本次设计将大卡片替换为横向标签栏，在保留分类可见性和直接访问能力的同时，
显著降低页面高度。

## 2. 设计目标

- 将分类区域桌面端总高度压缩至约 130px。
- 分类入口保持直接可见，不依赖下拉菜单。
- 桌面端分类保持单行排列。
- 手机端分类保持单行并允许横向滚动，避免重新变成长列表。
- 与 Mall 当前深色背景、绿色强调色和 Poppins 字体体系保持一致。
- 英文、中文和波斯语使用同一组件结构，波斯语正确支持 RTL。
- 保持现有分类筛选 URL、商品数据和页面跳转逻辑不变。

## 3. 布局

分类区域由两部分构成：

1. 24px 的分类标题。
2. 一行 40px 高的圆角分类标签。

标签顺序：

1. 全部产品。
2. 按目录数据返回顺序展示的具体分类。
3. 查看全部产品入口。

桌面端使用站点内容容器宽度，不限制固定列数。标签从页面阅读起始方向排列：

- 英文、中文从左至右。
- 波斯语从右至左。

分类区域使用紧凑的上下留白，不再沿用普通 Mall 内容板块最高 104px 的
区块间距。

## 4. 视觉规范

### 4.1 标题

- 字号：24px。
- 字重：500。
- 行高：1.2。
- 颜色：`#f4f7f5`。
- 字体栈沿用 Mall 当前语言字体规则，Poppins 保持第一优先级。

### 4.2 标签

- 高度：40px。
- 左右内边距：18px。
- 字号：14px。
- 字重：500。
- 圆角：999px。
- 文本不得强制换行。

默认标签：

- 背景：Mall 深色表面色。
- 边框：Mall 绿色透明细边框。
- 文字：`#f4f7f5`。

“全部产品”标签：

- 背景：`#5dd3a0`。
- 边框：`#5dd3a0`。
- 文字：`#04100b`。

悬停与键盘聚焦状态：

- 边框提高为清晰的绿色。
- 背景轻微提亮。
- 保留可见的 `focus-visible` 轮廓。
- 不引入位移幅度较大的动画。

## 5. 响应式规则

### 5.1 桌面端与平板端

- 所有标签保持在同一水平行。
- 当分类总宽度超过容器时，允许水平滚动。
- 隐藏原生横向滚动条，但保留触控板、鼠标滚轮横向手势和键盘访问。

### 5.2 手机端

- 分类标题保持 24px。
- 标签保持 40px 高和单行文本。
- 标签容器使用水平滚动，不换行。
- 首尾保留与页面内容边缘一致的安全间距。
- 不把标签改为纵向列表或大卡片。
- 页面自身不得产生横向溢出，只有标签容器内部可滚动。

### 5.3 波斯语

- 标签容器使用 RTL 排列。
- 初始滚动位置位于阅读起始侧。
- 标签内部英文型号保持自身可读的 LTR 字符顺序。

## 6. 交互与数据

- “全部产品”进入对应语言的 `/mall/products/`。
- 每个具体分类继续使用现有 `category` 查询参数进入筛选结果。
- “查看全部产品”进入对应语言的 `/mall/products/`。
- 不改变目录数据结构、分类名称、搜索行为和商品详情页。
- 标签由现有 `normalizedCategories(index)` 结果生成，不硬编码分类。

## 7. 无障碍

- 标签使用语义化链接。
- 键盘 Tab 顺序与视觉顺序一致。
- `focus-visible` 状态在深色背景下具备足够对比度。
- 水平滚动容器不得拦截页面正常的垂直触控滚动。
- 链接可点击区域高度保持 40px，手机端不因缩小布局而降低可操作性。

## 8. 验证标准

### 8.1 静态验证

- 三语言 Mall 首页仍引用统一分类组件和资源版本。
- 不再存在分类卡片的 144px 最小高度规则。
- 分类标签链接保持本地化路径与现有查询参数。
- 站点排版、Mall 路由和联系表单契约继续通过。

### 8.2 浏览器验证

覆盖英文、中文、波斯语：

- 桌面端 1440×900。
- 平板端 768×1024。
- 手机端 390×844。
- 波斯语 RTL。
- `prefers-reduced-motion: reduce`。

验证内容：

- 分类区域高度显著低于原设计。
- 桌面端标签单行排列。
- 手机端标签单行横向滚动。
- 分类点击后 URL 和筛选结果正确。
- 页面无整体横向溢出。
- 控制台无错误和警告。

## 9. 非目标

- 不重新命名或合并现有分类。
- 不增加分类图标或图片。
- 不修改商品卡片、商品详情页和数据抓取流程。
- 不修改 Mall Hero、搜索框和最近收录区域的视觉结构。
- 不修改主站其他页面的标签或按钮规范。
