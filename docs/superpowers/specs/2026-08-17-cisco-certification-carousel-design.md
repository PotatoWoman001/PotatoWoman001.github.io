# Cisco 资质证书滑动条设计

## 目标

在 Cisco 解决方案详情页中增加一组可连续滑动、可在当前页面放大查看的 Cisco 资质证书，作为 JOTO Cisco 专业能力的官方资质背书。

仅覆盖 Cisco 详情页的英文、中文和波斯语版本，不影响其他品牌解决方案页。

## 素材

使用用户提供的五份单页 Cisco 证书：

- Cisco Cloud and AI Infrastructure Partner
- Cisco Preferred Collaboration Partner
- Cisco Preferred Networking Partner
- Cisco Preferred Security Partner
- Cisco Services Partner

将证书页面转换为清晰、适合网页加载的图片。生产站只发布图片，不发布源 PDF，不提供 PDF 链接或下载按钮。图片保留 Cisco 官方英文内容，不改写证书文字。

## 页面位置与内容结构

证书区插入在 Cisco 专业能力介绍区之后、客户 Logo 墙之前。区块包含：

1. 本地化眉题；
2. 本地化标题和简短说明；
3. 单行证书滑动条；
4. 页面级图片灯箱。

英文、中文和波斯语只本地化区块界面文字，证书图片内容保持原样。

## 滑动条

- 使用五张证书卡片，并复制一组用于连续循环。
- 自动向左缓慢移动，速度低于客户 Logo 墙，保证证书内容可辨认。
- 桌面端约显示 2.5 张，iPad 约显示 1.8 张，手机约显示 1.15 张。
- 鼠标悬停、键盘聚焦或灯箱打开时暂停动画。
- 手机端允许触摸横向滚动。
- 用户启用 `prefers-reduced-motion: reduce` 时关闭自动动画，保留手动横向滚动。
- 轨道必须无可见跳变，且不得造成页面级横向溢出。

## 灯箱

- 点击或轻触任一证书，在当前页面打开深色遮罩灯箱。
- 灯箱展示更大的同一张证书图片，并提供本地化关闭按钮。
- 支持关闭按钮、点击遮罩和键盘 `Esc` 关闭。
- 打开灯箱时锁定背景滚动，关闭后恢复滚动并把焦点返回触发卡片。
- 不提供新窗口、PDF、下载按钮或下载链接。

## 实现方式

新增独立的 Cisco 证书增强 JS 和 CSS，通过当前路径及 Cisco 页面现有品牌标记限定作用范围。增强模块负责：

- 识别 Cisco 三语言详情页；
- 在指定区块之间插入证书区；
- 创建连续轨道、暂停状态和灯箱；
- 根据当前语言提供界面文案。

三种语言的 Cisco 静态入口只引用同一套版本化 JS/CSS。避免修改压缩后的 React 主程序，也不复制三套内容实现。

## 无障碍与安全边界

- 每张证书卡片使用按钮语义，并提供包含证书名称的 `aria-label`。
- 灯箱使用 `role="dialog"`、`aria-modal="true"` 和可访问标题。
- 重复轨道副本对辅助技术隐藏，避免重复朗读。
- 证书图片使用本地静态资源，不加载第三方内容。
- 网页无法从技术上完全阻止用户保存已显示的图片，但界面不提供下载能力，也不公开源 PDF。

## 验证标准

1. 英文、中文和波斯语 Cisco 页面均只出现一个证书区。
2. 五张证书全部显示，重复副本不被辅助技术重复读取。
3. 自动循环连续；悬停、聚焦和灯箱打开时暂停。
4. 灯箱可由点击、轻触和键盘打开，可由关闭按钮、遮罩和 `Esc` 关闭。
5. 桌面、iPad 和手机布局无裁切、重叠或页面级横向溢出。
6. 减少动态效果模式下无自动动画，并可手动横滑。
7. 页面和资源中没有源 PDF、PDF 链接或下载按钮。
8. 现有 Cisco 页面内容、客户 Logo 墙、联系表单和其他品牌页面保持不变。
