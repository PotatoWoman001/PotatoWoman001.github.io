# 中文移动端首屏内容整体下移设计

## 目标

在中文移动端首页中，将主标题、说明文字和两个 CTA 按钮作为同一内容组整体向下移动，使视觉位置由用户标注的 1 接近标注的 2。桌面端、英文和波斯语页面保持不变。

## 方案

沿用首页现有的移动端 Hero CSS 自定义属性体系，新增中文专属的内容组垂直偏移变量。常规手机使用随视口高度变化的 `clamp()` 偏移；短屏和窄屏单独降低偏移，避免 CTA 超出首屏。现有标题字号、行距、正文间距、按钮尺寸、背景光柱和链接均不修改。

## 作用范围

- 仅匹配 `html:lang(zh)`、移动端媒体查询和 `[data-home-hero-content]`。
- 430×932 与 390×844 上明显下移，接近用户标注位置 2。
- 375×667 与 320×568 上采用收敛后的偏移，两个 CTA 保持完整可见。
- 所有尺寸保持水平无溢出，下一节不侵入首屏。

## 验证

- 静态测试锁定中文作用域、常规屏偏移和短屏回收规则。
- 浏览器分别检查 430×932、390×844、375×667、320×568。
- 抽查英文和波斯语 430×932，确认没有新增偏移。
- 发布后检查线上中文首页的计算样式和实际几何位置。
