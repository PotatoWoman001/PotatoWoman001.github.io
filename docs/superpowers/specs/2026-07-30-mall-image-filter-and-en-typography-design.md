# Mall 无图商品过滤与英文首页局部排版设计

**日期：** 2026-07-30  
**状态：** 视觉与功能方向已确认，待实施  
**适用范围：** 三语言 Mall 列表；英文首页案例卡片与联系表单标题

## 1. 背景

当前 Mall 商品数据中存在两类不应出现在公开列表里的记录：

- `images` 为空，没有任何可展示图片。
- `images` 包含来源网站的 “No image available” 占位图。当前数据快照中，
  该占位图的文件名为
  `cd6a5082346e186283e0cf0f632762a1172f6ad74da5d9b7a9689974a7afbc84.webp`。

仅在渲染层隐藏卡片会使结果数量、分页和筛选统计不准确，因此需要在商品查询
入口统一排除这些记录。

英文首页还有两个局部排版问题：

- “Selected Experience” 案例卡片标题继承全站三级标题 `28px`，卡片内换行
  过多，不符合正文信息密度。
- 联系表单左侧标题 “Bring us the environment you need to improve.” 字号过大、
  行高过紧，当前在桌面端占用四行。

## 2. 设计目标

- 三语言 Mall 首页推荐、商品列表、搜索结果、筛选统计和分页均不展示无真实
  图片的产品。
- 已有商品详情直链继续可访问，不删除抓取数据。
- 对缺少图片数组和已知占位图文件名使用同一判定函数。
- 英文案例卡片标题改为正文级视觉，减少换行。
- 英文联系表单标题降低约两个字号级，改善行距。
- 不改变中文、波斯语排版，不修改全站字体变量。
- 不修改抓取站数据库、快照文件或商品详情内容。

## 3. 无图商品判定与数据流

### 3.1 单一判定函数

在 `assets/mall-data-client.js` 中导出：

```js
hasProductImage(product) -> boolean
```

规则：

1. `product.images` 必须为数组。
2. 至少存在一个非空图片路径。
3. 图片路径最后一段的文件名不能属于已知占位图集合。

已知占位图集合初始包含：

```text
cd6a5082346e186283e0cf0f632762a1172f6ad74da5d9b7a9689974a7afbc84.webp
```

文件名比较使用小写，忽略查询参数和 URL hash。未来确认新的来源占位图时，只
向该集合增加对应文件名，不在页面组件中分散判断。

### 3.2 商品列表

`queryProducts()` 在搜索、分类、品牌、状态、排序和分页之前先过滤来源数据：

```text
index.products
  → hasProductImage
  → 搜索及筛选
  → 排序
  → 分页
```

因此 `total`、`totalPages`、分类/品牌/状态/成色 facets 都只基于可展示产品。

### 3.3 Mall 首页

`assets/mall-catalog-pages.js` 的最近收录推荐在排序和截取前调用同一个
`hasProductImage()`。首页推荐与商品列表不会产生不同的无图判断。

### 3.4 商品详情

`loadProduct()` 不应用该过滤。已有详情 URL 继续加载商品信息，便于后续补图
后自动恢复到公开列表，也避免已收录链接立即变成 404。

## 4. 英文案例卡片排版

仅对：

```css
html:lang(en) #case-studies .group > .flex-1 h3
```

应用：

- 字号：`16px`。
- 行高：`24px`。
- 字重：`500`。
- 最大宽度：取消当前 `235px` 的额外限制，使用内容列可用宽度。
- 对齐：保持左对齐。
- 字体：继续使用 Poppins。

标签维持单行；Logo、标题和标签所在内容列的居中规则保持不变。

## 5. 英文联系表单标题排版

仅对：

```css
html:lang(en) #contact .joto-home-contact__copy h2
```

应用：

- 字号：`clamp(36px, 3.2vw, 48px)`。
- 行高：`1.12`。
- 字重：保持 `500`。
- 字距：由当前 `-0.055em` 收敛至 `-0.04em`。
- 最大宽度：`32rem`。

目标是在 `1440px` 桌面视口中从当前四行缩减为约三行，同时不改变右侧表单
宽度和联系板块网格比例。平板与手机继续使用 clamp 的较小端。

## 6. 验证标准

### 6.1 静态与数据验证

- 无图片数组的测试产品不会出现在 `queryProducts()` 结果。
- 只有已知占位图的测试产品不会出现在结果。
- 至少包含一张真实图片的测试产品正常保留。
- `total`、分页和 facets 不包含被排除产品。
- Mall 首页代码使用与查询层相同的 `hasProductImage()`。
- 英文字体覆盖只包含 `html:lang(en)`，不修改全站字号变量。

### 6.2 浏览器验证

覆盖英文、中文、波斯语与 `1440×900`、`768×1024`、`390×844`：

- DI-7008-MINI 占位图产品不再出现在 Mall 首页、商品列表和搜索结果。
- 页面结果数量从当前 16 件减少为 15 件。
- 分页、筛选、排序、网格/列表视图继续工作。
- 商品详情直链仍可访问。
- 英文案例卡片标题计算字号为 `16px`、行高为 `24px`。
- 英文联系标题桌面计算字号不超过 `48px`、行高为 `1.12`。
- 中文和波斯语对应元素字号不受英文覆盖影响。
- 页面无横向溢出，控制台无错误或警告。

## 7. 非目标

- 不删除或重写抓取快照。
- 不对图片内容运行 OCR 或视觉识别。
- 不隐藏只有图片加载失败但数据路径正常的产品。
- 不修改商品详情页的图片占位表现。
- 不调整中文或波斯语案例卡片及联系标题。
- 不改变案例卡片结构、Logo、标签内容或联系表单字段。
