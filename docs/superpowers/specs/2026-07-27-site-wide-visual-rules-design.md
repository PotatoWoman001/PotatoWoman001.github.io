# JOTO Global 全站视觉规则更新设计

## 1. 目标

依据已经确认的《JOTO Global 网站修改规则》，统一三种语言、105 个路由页面的英文排版、内容边界、行动按钮和页头品牌副标题。所有修改只保存在本地维护分支，完成整体验证前不推送、不部署。

规则来源：

- `docs/site-modification-rules.md`

## 2. 当前实现与修改边界

当前仓库保存的是已经编译完成的静态站点，不包含 React/Vite 原始工程。所有路由 HTML 都加载同一份共享 CSS 和 JavaScript：

- `assets/index-e49ffBFL.css`
- `assets/index-DaFvN0XI.js`

因此，全站规则应优先在共享资源中集中实现，不能逐个修改 105 份路由 HTML。首页、About、Contact、Blog、解决方案分类页、厂商详情页和 404 页面均纳入验证范围。

本次不修改页面文案、业务内容、SEO 数据、图片、动画节奏、路由、表单逻辑或部署配置。

## 3. 英文字体设计

### 3.1 默认字体

所有普通英文界面文字统一使用网站已有的本地 `Poppins` 字体，覆盖导航、标题、正文、说明、按钮、表单、卡片、页脚、英文标签和技术型装饰文字。

实现时需要替换当前默认的 `Inter`、`Plus Jakarta Sans` 和等宽字体显示规则，并继续使用现有的 `Poppins` 400、500、600、700、800 字重文件。

### 3.2 唯一视觉例外

绿色 `Instrument Serif` 衬线文字以及具有打字、闪现或闪回效果的绿色衬线片段继续保留原字体、斜体表现和动画节奏。

字体调整不能改变中文与波斯语的可读性。中文与波斯语字符在 `Poppins` 不包含相应字形时继续使用适合该语言的后备字体，但其中的英文和拉丁字符优先使用 `Poppins`。

## 4. 文本框边界与方向设计

每个页面模板建立一致的内容容器和语言起始基准线：

- 英文和中文：标题、正文与按钮区域共用左侧起始线。
- 波斯语：采用镜像布局，共用右侧起始线。
- 标题可比正文使用更宽的文本框，但不得越过统一内容边界。
- 文本自然换行，不使用强制两端拉伸。
- 桌面、平板和手机仅调整容器宽度与间距，不改变同一区域的对齐关系。

需要核对的共享模板包括：

1. 全局页头和页脚；
2. 首页各内容章节；
3. About 与 Contact 页面；
4. Blog 列表页与文章详情页；
5. 五个解决方案分类页；
6. 二十个厂商详情页；
7. 404 页面。

## 5. 两级按钮系统

### 5.1 紧凑按钮

- 固定宽度：`96px`
- 固定高度：`36px`
- 用途：短文案行动入口，例如页头 `Contact`

### 5.2 标准 CTA

- 桌面和平板宽度：`280px`
- 高度：`48px`
- 手机宽度：`100%`
- 手机最大宽度：`280px`
- 用途：主要行动入口，例如 `Explore Solutions`、`Learn more`、`Contact JOTO`、案例入口和表单提交

按钮文字和图标必须垂直居中。英文和中文采用从左到右排列；波斯语采用镜像排列。标准 CTA 的文案必须在既定宽度内保持可读，不得被截断。

地图定位圆点、语言选择器、菜单开关、轮播控制等功能控件保持自身功能尺寸，不纳入两级行动按钮系统。

## 6. 页头品牌副标题

所有页面共用的页头品牌区域从：

```text
TECH
SHANGHAI
```

修改为：

```text
Global IT
Service Provider
```

显示时保留上述大小写和换行，不使用全大写转换。三种语言页面使用相同英文副标题。该修改只影响页头视觉标识，不替换正文、SEO 元数据或公司法定名称中的 `JOTO TECH`。

## 7. 验证方案

### 7.1 桌面端

使用约 1440px 宽度检查三种语言的代表页面：

- 首页；
- About；
- Contact；
- Blog 列表与文章详情；
- 一个解决方案分类页；
- 一个厂商详情页；
- 404 页面。

### 7.2 手机端

使用约 390px 宽度重复检查上述模板，重点确认：

- 内容不横向溢出；
- 标题、正文和 CTA 起始线一致；
- 波斯语为镜像右对齐；
- 标准 CTA 不超过 280px；
- 按钮文案不截断；
- 页头品牌副标题保持两行且不与导航冲突。

### 7.3 自动核对

- 普通英文元素的计算字体为 `Poppins`；
- 绿色衬线动画元素仍为 `Instrument Serif`；
- 紧凑按钮为 `96 × 36px`；
- 标准 CTA 桌面端为 `280 × 48px`；
- 三种语言的共享页头均显示 `Global IT` 和 `Service Provider`；
- Git 工作区中不出现部署配置或无关内容变化。

## 8. 完成标准

上述规则在所有共享页面模板和三种语言中生效，桌面与手机检查均通过，且用户确认本地预览结果后，本阶段才算完成。推送与部署属于后续独立步骤，必须由用户明确授权。
