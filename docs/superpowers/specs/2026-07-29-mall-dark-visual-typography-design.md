# JOTO Mall 深色视觉与字体统一设计

## 1. 目标

将三语言 Mall 从独立的浅色网格子站视觉，统一为 JOTO Global 官网现有的
黑绿设计体系，并解决以下问题：

1. Mall 背景和组件结构与官网不一致；
2. 产品详情页显示“来源 / 原网页”及外部链接；
3. Mall 标题、正文和按钮字号偏大；
4. 英文与拉丁字符的视觉表现没有稳定遵循本地 `Poppins` 字体规范。

本次只修改 Mall 首页、产品列表页、产品详情页及其共享资源，不改变爬虫
快照结构、产品数据内容、搜索筛选逻辑、联系表单预填逻辑、站点其他页面
或发布架构。

## 2. 已确认的视觉方向

采用 A 方案“官网深色延续”：

- 使用官网现有黑绿背景、绿色强调色、低对比细边框和克制字号；
- 删除 Mall 浅色纸张背景及网格纹理；
- 产品卡片、搜索、筛选、分页、详情表格和联系面板全部使用深色组件；
- Mall 继续保持产品目录的清晰浏览效率，但不再呈现为独立电商子站；
- 英文、中文和波斯语使用同一布局系统，波斯语保持 RTL 镜像关系。

## 3. 色彩与背景

Mall 共享 CSS 在 `[data-joto-mall]` 范围内使用以下语义变量：

```css
--mall-bg: #050a08;
--mall-surface: #08110d;
--mall-surface-raised: #0c1712;
--mall-ink: #f4f7f5;
--mall-muted: rgba(244, 247, 245, 0.62);
--mall-green: #5dd3a0;
--mall-line: rgba(146, 170, 159, 0.22);
```

具体规则：

- 页面主背景为 `--mall-bg`；
- Hero 允许使用克制的绿色径向渐变，但不得出现浅色大块背景；
- 卡片和表格使用 `--mall-surface` 或 `--mall-surface-raised`；
- 所有分隔线与卡片边框使用 `--mall-line`；
- 交互强调、链接、状态和主要按钮使用 `--mall-green`；
- 删除 `.joto-mall__grid-field` 的网格背景图；
- 产品图片区域保持中性深色，确保白底产品图仍可辨认。

## 4. 字体与字号

### 4.1 字体家族

Mall 不使用绿色斜衬体例外。语言字体栈固定为：

```css
html[lang^="en"] [data-joto-mall] {
  font-family: Poppins, sans-serif;
}

html[lang^="zh"] [data-joto-mall] {
  font-family: Poppins, "PingFang SC", "Microsoft YaHei", sans-serif;
}

html[lang^="fa"] [data-joto-mall] {
  font-family: Poppins, Vazirmatn, sans-serif;
}
```

按钮、输入框、选择器和文本域必须继承上述字体。中文与波斯语字形分别由
语言后备字体显示，英文、品牌名、缩写、数字和产品型号优先由 `Poppins`
显示。

### 4.2 字号层级

| 元素 | 桌面 | 平板 | 手机 | 行高 | 字重 |
|---|---:|---:|---:|---:|---:|
| Mall Hero 标题 | `56px` | `44px` | `34px` | `1.12` | `500` |
| 列表与详情主标题 | `48px` | `40px` | `32px` | `1.12` | `500` |
| 板块标题 | `40px` | `34px` | `28px` | `1.18` | `500` |
| 详情小节标题 | `28px` | `26px` | `22px` | `1.24` | `500` |
| 分类与卡片标题 | `18px` | `18px` | `17px` | `1.35` | `500–600` |
| Hero 引导正文 | `16px` | `16px` | `15px` | `1.75` | `400` |
| 标准正文 | `14px` | `14px` | `14px` | `1.65` | `400` |
| 标签与筛选器 | `12px` | `12px` | `12px` | `1.5` | `500–600` |
| 辅助信息 | `11px` | `11px` | `11px` | `1.5` | `400–600` |

标题字距保持 `-0.02em` 至 `-0.035em`，不继续使用当前 Mall Hero 的
`-0.065em`。正文不设置负字距。正常可读文字不得小于 `11px`。

## 5. 组件规则

### 5.1 Hero 与搜索

- Hero 上下间距缩短到官网板块常用节奏；
- 标题最大宽度控制在约 `760px`；
- 搜索框使用深色透明面板、圆角胶囊边框；
- 搜索按钮使用绿色实底和深色文字；
- 输入文字、占位符和按钮保持 `14px`，不得继承 Hero 大字号。

### 5.2 分类与产品卡片

- 分类卡片和产品卡片使用深色表面及细边框；
- 分类标题 `18px`，产品标题 `18px`；
- 产品图片区使用 `--mall-surface-raised`；
- 摘要正文 `14px`，最多三行；
- 品牌、型号和辅助标签为 `11–12px`；
- 悬停仅使用轻微边框、背景和图片缩放变化，避免突兀动效。

### 5.3 筛选、分页与视图切换

- 筛选标签为 `12px`，选择器和输入内容为 `14px`；
- 控件使用深色背景、细边框和绿色焦点状态；
- 当前视图与主要操作使用绿色强调；
- 不改变 URL 状态、浏览器前进后退或分页逻辑。

### 5.4 产品详情

- 图片画廊使用深色中性表面；
- 标题、元数据、规格表、资料下载和相关产品统一为深色组件；
- 桌面继续保留详情摘要的 sticky 行为，平板和手机恢复普通文档流；
- 手机联系入口继续可见并使用官网按钮规范；
- 产品 JSON-LD、SEO 元数据和联系表单产品预填保持不变。

## 6. 来源信息处理

产品详情页不得显示：

- “Source / 来源 / منبع”标题；
- 来源 URL；
- “原网页”或任何等价的外部来源标注；
- 指向被抓取页面的可见链接。

`source_url` 可以继续保留在不可见的快照数据中，供内部追踪、去重和运维
使用，但 Mall 前端不得读取或渲染该字段。三语言 `mall-i18n.js` 中仅服务
于可见来源板块的 `source` 文案一并删除。

## 7. 响应式与可访问性

- 桌面宽度 `1440px`、平板 `768px`、手机 `390px` 均不得横向溢出；
- 中文和英文使用 LTR，波斯语使用 RTL；
- 焦点状态必须在深色背景上保持可见；
- 文本与背景满足可读对比；
- `prefers-reduced-motion: reduce` 下关闭非必要过渡；
- 产品图片、按钮、筛选器和状态提示保留现有语义与无障碍属性。

## 8. 验证范围

### 8.1 静态验证

- Mall CSS 明确包含三语言字体栈；
- Mall Hero、板块、卡片和正文使用本设计的字号范围；
- `.joto-mall__grid-field` 不再输出网格背景图；
- `mall-product-page.js` 不再读取或渲染 `product.source_url`；
- 三语言 `source` 可见文案从 Mall 国际化资源中删除；
- 现有 Mall 数据、路由、联系表单与站点规则验证继续通过。

### 8.2 Playwright 浏览器验证

在本地 Docker 和 `https://jotoglobal.com` 分别检查：

- 英文、中文、波斯语；
- `1440 × 900`、`768 × 1024`、`390 × 844`；
- 首页、产品列表、产品详情；
- 搜索、分类、品牌、排序、视图、分页、前进后退；
- 产品图片、详情内容、联系表单预填；
- 详情页不存在可见来源标注和来源 URL；
- 英文和拉丁元素计算字体以 `Poppins` 开头；
- 页面背景为深色且不存在浅色网格；
- RTL、减少动态效果、无横向溢出；
- 控制台错误和页面错误均为 0。

## 9. 完成标准

三语言 Mall 在视觉上成为 JOTO Global 官网的自然延伸，所有可见来源标注
被删除，字号层级符合全站规范，英文与拉丁字符稳定使用本地 `Poppins`。
静态检查、本地 Docker 浏览器矩阵与生产环境浏览器矩阵全部通过后，创建
新提交并以新版本目录发布，不覆盖历史线上版本。
