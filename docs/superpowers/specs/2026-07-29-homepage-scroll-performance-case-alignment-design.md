# 首页滚动性能与案例卡片对齐设计

## 目标

在不改变首页信息架构、卡片顺序和三语言内容的前提下，解决以下三个已确认的问题：

1. 英文首页案例卡片的 Logo 与标题文本框视觉中轴不一致。
2. 案例卡片底部的三个 Tag 会换行。
3. `What we deliver` 卡片过高、进入区块时提示动画过长，且悬停会改变布局高度，导致纵向滚动体感卡顿。

## 设计范围

### 1. 英文案例标题文本框

- 英文首页 `#case-studies` 的案例标题容器固定为最大 `235px`。
- 标题容器水平居中，与卡片 Logo 共用同一条视觉中轴。
- 标题文字在容器内部保持左对齐，不改变既有信息阅读方向。
- 中文和波斯语沿用当前已经确认的对齐方式。

### 2. 案例 Tag

- 每张案例卡片的三个 Tag 必须保持在同一行。
- Tag 列表使用 `flex-wrap: nowrap`，间距由 `6px` 收紧为 `4px`。
- Tag 自身禁止断词与换行，保持现有字号和胶囊外观。
- 在 `390px` 手机视口下仍需保持单行，且不得造成页面横向溢出。

### 3. What we deliver 卡片尺寸

为减少卡片占用的纵向空间并缩短用户穿过该区块的滚动距离，使用三档固定尺寸：

| 视口 | 卡片高度 | 图片区域高度 |
| --- | ---: | ---: |
| `< 640px` | `410px` | `320px` |
| `640px–1279px` | `430px` | `340px` |
| `≥ 1280px` | `440px` | `350px` |

- CTA 保持在卡片底部，不再通过 `bottom` 或高度变化产生布局位移。
- 图片仅保留轻微缩放反馈，时长收敛到 `320ms`。
- 卡片启用布局与绘制隔离，避免单张卡片的视觉更新影响整个横向列表。

### 4. 横向提示动效

- 每次页面刷新后最多播放一次，保留“这里可以左右切换”的提示意义。
- 最大提示位移从 `120px` 调整为 `72px`。
- 动效节奏调整为：
  - 向前：`260ms`
  - 停留：`80ms`
  - 返回：`260ms`
  - 总时长约 `600ms`
- 任意纵向或横向滚轮输入都立即取消提示动效，把控制权交还给用户。
- 横向吸附由 `mandatory` 调整为 `proximity`，降低纵向滚动经过该区块时的干扰。
- 系统开启 `prefers-reduced-motion: reduce` 时不播放提示。

## 实现边界

- 不修改主打包文件 `assets/index-DaFvN0XI.js` 的业务组件结构。
- 通过现有增强层 `assets/homepage-refinements.css`、`assets/solution-card-carousel.css` 和 `assets/solution-card-carousel.js` 完成覆盖。
- 不改变卡片文案、图片、顺序、链接和左右按钮逻辑。
- 英文、中文、波斯语首页共用同一套性能优化；英文案例标题宽度仅对 `lang="en"` 生效。
- 静态资源版本统一升级为 `20260729-2`，确保本地与线上浏览器不会继续使用旧缓存。

## 验收标准

1. 英文案例卡片中，Logo 中心与标题容器中心偏差不超过 `2px`。
2. 三语言首页的案例 Tag 均为单行，`390px` 手机视口没有页面级横向溢出。
3. `1440px` 桌面视口中，解决方案卡片为 `440px`、图片区为 `350px`。
4. `390px` 手机视口中，解决方案卡片为 `410px`、图片区为 `320px`。
5. 悬停或聚焦卡片时，卡片与图片区域高度不变化。
6. 提示动效总时长约 `600ms`、最大位移不超过 `72px`；纵向滚轮输入会立即取消提示。
7. 左右按钮、首尾禁用状态、LTR/RTL 方向和卡片逐张切换无回归。
8. 英文、中文、波斯语桌面与手机页面均无控制台错误、无页面级横向溢出。
