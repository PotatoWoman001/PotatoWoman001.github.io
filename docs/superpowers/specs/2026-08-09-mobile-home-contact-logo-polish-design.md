# 移动端首页、表单与技术品牌墙细节优化设计

**日期：** 2026-08-09  
**状态：** 用户已确认，允许直接实施  
**适用范围：** 英文、简体中文与波斯语首页，以及复用联系表单的 Solution 页面

## 1. 目标

修正移动端首页 Hero 顶部空白过多、技术品牌墙末行缺位、联系表单提示文字层级过重，以及提交按钮箭头在不同手机系统中显示不一致的问题。修改保持现有桌面端结构和品牌风格，不重构主 bundle。

## 2. 已确认的界面规则

### 2.1 移动端 Hero

- 英文、简体中文和波斯语首页的 Hero 主内容整体上移，减少导航下方到主标题之间的无效空白；
- 主标题、说明文字和两个 CTA 作为一个整体移动，保持内部间距与按钮对齐关系；
- 仅作用于手机断点，不改变桌面端已确认的居中布局；
- 不引入额外滚动监听或持续动画，避免影响首屏性能。

### 2.2 技术品牌墙

- 在现有 20 个技术品牌之后加入 **Juniper Networks**，手机端总数变为 21；
- 手机端保持三列布局，使最后一行完整显示三个品牌，不保留空白格；
- 新 Logo 使用本地透明 SVG 资源，图片具备准确的 `alt` 文本；
- 不改变现有品牌顺序，Juniper Networks 作为最后一项补位；
- `1024px` 及以上继续显示原有 20 项，避免桌面五列网格出现孤立的第 21 项；
- 英文、中文、波斯语首页共用同一品牌资产，波斯语保持 RTL 页面方向但不镜像 Logo 本身。

### 2.3 联系表单提示层级

- 输入框与文本域的 placeholder 字号低于字段标签；
- placeholder 使用更浅、更低对比度的中性颜色，但仍满足可读性；
- “标有 * 的字段为必填项”等辅助提示同步降低字号和视觉权重；
- 字段标签、用户实际输入文字及错误信息保持现有清晰度，不随 placeholder 一起变浅；
- 首页与 Solution 详情页中复用的三语言联系表单采用同一规则。

### 2.4 提交按钮箭头

- 移除 Unicode `↗` 字符实现；
- 改为内联 SVG 右上箭头，置于深色圆形底中；
- SVG 使用 `currentColor`，保持线宽、端点和方向在 iOS、Android 与桌面浏览器一致；
- 图标为装饰元素，保留 `aria-hidden="true"`，按钮的可访问名称继续由本地化按钮文字提供。

## 3. 实现方式

沿用项目当前“静态 bundle + 可审计增强资产”的集成模式：

- `assets/homepage-refinements.css` 负责手机 Hero 位移；
- `assets/homepage-refinements.js` 负责在品牌墙安全、幂等地补充 Juniper Networks；
- `assets/contact-form-sections.js` 输出内联 SVG 按钮图标；
- `assets/contact-form-sections.css` 统一 placeholder、辅助提示和按钮图标样式；
- 新增本地 Juniper Networks SVG 资产，不依赖运行时外部图片；
- 对应集成脚本与验证脚本同步更新，确保重新集成时不会丢失改动。

运行时增强必须具备幂等性：页面已包含 Juniper Networks 时不得重复插入；目标品牌墙不存在时静默退出，不影响其他页面。

## 4. 响应式与兼容性

- 手机验证视口：`390 × 844` 与 `430 × 932`；
- 桌面回归视口：`1440 × 900`；
- 英文和中文为 LTR，波斯语为 RTL；
- 页面不得产生新的横向溢出；
- Juniper Logo 在白色品牌卡片中按 `object-fit: contain` 显示；
- 提交 SVG 不依赖系统字体，避免不同设备出现方框、Emoji 或字形差异。

## 5. 验证范围

### 5.1 静态验证

- 三语言首页继续加载 homepage refinement CSS/JS；
- Juniper Networks 插入逻辑和 SVG 资产存在，重复执行不产生重复项；
- 联系表单中不再存在 Unicode `↗`；
- placeholder、辅助提示和 SVG 图标规则存在；
- 既有 homepage/contact 集成验证脚本通过。

### 5.2 浏览器验证

- 三语言首页手机端 Hero 明显上移且不遮挡导航；
- 三语言品牌墙均为 21 项，手机端最后一行三项完整；
- Juniper Logo 正常加载，无空图或拉伸；
- 首页和 Cisco Solution 联系表单的提示词更小、更浅；
- 提交按钮在桌面与手机端显示深色圆形底和右上 SVG 箭头；
- 英文、中文、波斯语页面无横向溢出，控制台无新增错误。

## 6. 非目标

- 不改变桌面 Hero 的排版和尺寸；
- 不重排或删除现有 20 个技术品牌；
- 不修改联系表单字段、校验、提交接口或文案内容；
- 不调整 Solution 页面其他视觉模块；
- 不在本轮改动中引入第三方前端依赖。
