# JOTO Global 首页 Hero、滚动性能与波斯语地图增强设计

## 1. 目标

本次更新在当前已确认的 JOTO Global 首页版本上完成四组调整：

1. 重新排版三语言首页 Hero，使桌面端主内容从左下角移动到页面视觉中心；
2. 统一中文正式页面的标题行距，解决中文展示标题过于拥挤的问题；
3. 让“核心能力”板块在每次刷新后首次进入视口时播放一次轻微横向提示，同时解决纵向滚动误取消和卡顿；
4. 仅在波斯语首页的全球布局地图与国家栏增加伊朗。

本设计采用独立增强层方案。已有 React 主包保持不变，变化集中在现有首页增强 CSS/JS 与轮播增强文件中，降低 108 个正式路由的回归风险。

## 2. 已确认的 Hero 方向

### 2.1 删除内容

三语言首页统一删除：

- Hero 主标题上方的小标题：
  - 英文：`ENTERPRISE-READY IT SOLUTIONS`
  - 中文：`企业级 IT 解决方案`
  - 波斯语：对应本地化文本
- 右上方包含 `[ SINCE 2010 ]` / `[ 始于 2010 ]` 的完整信息卡，包括边框、标题、强调文案和说明文字。

删除后不保留空容器，背景视频和网格必须自然填充原区域。

### 2.2 桌面布局

桌面端以 `1024px` 为起始断点：

- Hero 主标题、说明和两个 CTA 组成一个不可拆分的内容组；
- 内容组水平中心与视口水平中心对齐；
- 内容组垂直中心位于首屏几何中心略偏上，避免继续停留在左下角；
- 内容组最大宽度约 `680px`，实际宽度随标题和视口收敛；
- 内容组内部仍按语言阅读方向对齐：
  - 英文、中文：左对齐；
  - 波斯语：右对齐；
- Hero 主标题、说明文字共享同一左右边界；
- 主标题第一行和第二行的起始边缘与说明文字起始边缘对齐；
- 标题末尾品牌绿点与说明文字结束边缘形成同一视觉边界；
- 两个 CTA 保持同一尺寸、同一行排列，并与正文起始边缘对齐。

英文和波斯语允许根据字符长度使用各自的自然最大宽度，但内容组的中心位置、CTA 规则和信息层级保持一致。

### 2.3 平板与手机

- `1023px` 以下保持当前安全流式布局，不强制绝对居中；
- 不允许标题与页头、语言菜单或 CTA 重叠；
- 不允许产生横向页面溢出；
- 小标题和右上信息卡仍保持删除状态。

## 3. 中文标题行距规范

### 3.1 范围

仅调整 `html:lang(zh)` 下正式页面的 `h1–h4`：

- 首页；
- About；
- Contact；
- Blog 列表和文章；
- Solution 分类页；
- Solution 厂商详情页；
- Mall；
- 其他正式静态路由。

正文、按钮、标签、表单字段和辅助文字保持现有行距。英文和波斯语页面保持现状。

### 3.2 Token 规则

中文标题行高不得低于 `1.2`：

| 层级 | 当前值 | 中文目标值 |
|---|---:|---:|
| T0 Hero / 展示标题 | `0.92` | `1.20` |
| T1 页面主标题 | `1.00` | `1.20` |
| T2 板块标题 | `1.08` | `1.20` |
| T3 主要卡片标题 | `1.20` | 保持 `1.20` |
| T4 普通卡片标题 | `1.30` | 保持 `1.30` |

这是一条“最小行高”规则，而不是把所有现有值再次乘以 `1.2`。这样能够放松展示标题，同时避免卡片标题变得过散。

首页中文 Hero 使用 `1.20`，且动态绿色关键词切换时不得改变整行高度或导致标题跳动。

## 4. 核心能力滑动提示与滚动性能

### 4.1 现状问题

现有提示逻辑已经通过 `IntersectionObserver` 触发，但存在两项问题：

1. 纵向滚轮事件落在横向滚动器上时，会被当成轮播用户操作，提示尚未完成就被取消；
2. 提示动画每一帧直接写入 `scrollLeft`，会与页面纵向滚动和其他进入动画争用主线程，造成卡顿。

### 4.2 新触发规则

- 每次完整刷新页面最多播放一次；
- 不使用 `sessionStorage` 或 `localStorage` 跨刷新记忆；
- `#solutions` 可见比例达到约 `32%` 时触发；
- 仅在滚动器处于第一张时执行；
- 动画开始前若用户已经进行横向操作，则不播放；
- `prefers-reduced-motion: reduce` 时不播放。

### 4.3 新动作

- 使用浏览器原生平滑滚动，不再逐帧写入 `scrollLeft`；
- 沿内容前进方向移动约下一张卡片间距的 `30%`，最大不超过 `120px`；
- 到达提示位置后短暂停留，再平滑回到第一张；
- LTR 与 RTL 自动镜像；
- 动画完成后恢复滚动吸附并重新计算左右按钮状态；
- 提示完成后数据状态标记为 `complete`，本次页面生命周期内不再重复播放。

### 4.4 用户控制

以下操作立即取消自动提示并交还控制权：

- 横向滚轮或 `Shift + Wheel`；
- 指针拖动；
- 触摸滑动；
- 键盘操作；
- 点击左右轮播按钮。

普通纵向滚轮不取消提示，也不阻止页面自然向下滚动。

### 4.5 性能边界

- 自动提示期间不得通过循环产生同步布局读取和写入；
- `scroll` 状态更新继续合并到单个 `requestAnimationFrame`；
- 不增加全局滚动监听器；
- 不增加循环自动播放；
- 动画期间不得出现超过 `50ms` 的新增长任务；
- 桌面和手机端纵向滚动不能出现页面横向位移。

## 5. 波斯语首页伊朗节点

### 5.1 数据

仅波斯语首页新增：

- 国家：`ایران`
- 城市：`تهران`
- 地图节点 ID：`tehran`
- 区域键：`Iran`

Tehran 使用联合国地名数据库给出的坐标：

- 纬度：`35.71219607`
- 经度：`51.36844735`
- 数据来源：<https://ungegn.un.org/dashboard/cities/details?id=79>

按当前地图投影公式计算基础位置：

- `x = (longitude + 180) / 360 × 100 ≈ 64.27%`
- `y = 55 - latitude × 0.45 ≈ 38.93%`

最终允许增加少量 `artworkOffsetX`，以适配现有世界地图美术资源。

### 5.2 地图表现

- 在波斯语地图增加 Tehran 标记；
- 从现有长三角中心节点增加一条到 Tehran 的虚线路径；
- 标记悬停或聚焦时显示 `ایران / تهران`；
- 支持键盘聚焦；
- 使用现有绿色标记、脉冲和焦点样式；
- 保持 RTL 文案方向。

### 5.3 国家栏

- 波斯语国家栏由 6 张卡片增加为 7 张；
- 第七张卡片显示 `ایران` 和 `تهران`；
- 桌面端右侧国家栏自动调整为 7 行；
- 平板双列布局允许最后一张卡片独占一项，不造成溢出；
- 英文和中文页面仍保持 6 张国家卡片，DOM 中不出现 Iran / 伊朗 / `ایران`。
