# 首页交互与内容精修设计

## 1. 目标

在英文、中文和波斯语首页统一完成五组精修：

1. 缩短 Hero 行动按钮，并统一页头 Contact 与语言选择器的尺寸；
2. 为“核心能力”横向卡片增加一次性的滑动提示；
3. 将“全生命周期服务”的六个图标改为纯绿色；
4. 删除“选择 JOTO”的第二段补充正文，并重排四张统计卡；
5. 在首页“联系 JOTO”板块加入与 Solution 详情页一致的联系表单。

本设计以当前维护分支 `0c5a2cb` 为基础。修改先在本地 Docker 中完成并验证；提交、推送和线上发布属于实现完成后的独立步骤。

## 2. 当前实现与约束

仓库保存的是编译后的静态站点，不包含 React/Vite 原始工程。三语言首页共用主 CSS 与主 JavaScript，并额外加载以下渐进增强资源：

- `assets/solution-card-carousel.js`
- `assets/solution-card-carousel.css`
- `assets/contact-form-sections.js`
- `assets/contact-form-sections.css`

首页目前有五张“核心能力”卡片，不新增第六个解决方案类别：

1. 网络；
2. 安全；
3. 服务器与存储；
4. 协作通信；
5. 物理安防。

现有左右控制按钮、逐卡滚动、隐藏原生滚动条、三语言路由、RTL 行为和 `/api/contact` 接口继续保留。

## 3. 按钮设计

### 3.1 Hero 行动按钮

首页 Hero 的“查看解决方案”和“联系我们”不再使用全站标准 CTA 的固定 `280px` 宽度。首页 Hero 作为明确例外，采用内容自适应宽度：

- 高度：`48px`；
- 宽度：`auto`；
- 最小宽度：`0`；
- 左右内边距：`28px`；
- 文案：单行，不截断；
- 两个按钮间距：`12px` 至 `16px`；
- 默认保持同一水平行；
- 容器空间不足时整颗按钮换行，不允许按钮文字内部换行；
- 手机端不再强制 `width: 100%` 或 `max-width: 280px`。

两个按钮的宽度由各自本地化文案决定，不要求彼此等宽。波斯语按钮内部文字与箭头遵循 RTL 镜像。

### 3.2 页头按钮

页头 Contact 按钮与语言选择器统一为：

- 宽度：`96px`；
- 高度：`36px`；
- 左右内边距：`0`；
- 内容水平、垂直居中；
- 文案和下拉箭头保持单行。

该规则在三种语言和所有正式路由的共享页头中生效。菜单开关继续使用原有圆形功能控件尺寸。

### 3.3 规则优先级

现有 `docs/site-modification-rules.md` 中的两级按钮系统继续适用于普通页面。首页 Hero 内容宽度按钮是经本设计确认的局部例外；表单提交按钮仍保持详情页既有的 `280 × 48px` 标准 CTA 规范，不受 Hero 自适应宽度影响。

## 4. “核心能力”滑动提示

采用已确认的 B 方案：卡片向左轻推一小段，再回到第一张。

### 4.1 触发条件

- 使用 `IntersectionObserver` 观察 `#solutions`；
- 板块首次进入视口且可见比例达到 `35%` 时触发；
- 每次页面加载最多执行一次；
- 仅在滚动器位于起始位置时执行；
- 若用户已通过触摸、指针、滚轮、键盘或左右控制按钮操作轮播，则取消尚未开始的提示。

### 4.2 动作

- 延迟 `180ms`，避免进入视口瞬间抢夺注意力；
- 沿内容前进方向移动卡片宽度的 `35%`，但不超过 `120px`；
- 移动时长 `520ms`；
- 停留 `420ms`；
- 再以 `620ms` 回到第一张；
- 动画完成后更新左右按钮的首尾状态。

LTR 页面视觉上向左移动卡片轨道；RTL 页面按内容方向镜像，露出下一张卡片。提示不改变最终活动卡片。

### 4.3 用户控制与无障碍

- 动效执行期间如果用户开始操作，立即停止自动提示并保留用户位置；
- `prefers-reduced-motion: reduce` 时不执行自动位移；
- 动效不循环、不自动播放下一张、不产生额外提示音或文字；
- 原左右按钮、键盘焦点和触摸滚动始终可用。

## 5. “全生命周期服务”图标

六张服务卡当前使用两份重叠 SVG：绿色底图和白色裁切强调层。本次保留底层 SVG，并隐藏白色强调层：

- `.service-card__icon-mark--accent` 不再显示；
- 主图标统一使用现有 JOTO 绿色；
- 悬停时仅增强绿色亮度、阴影和已有轻微位移；
- 不改变图标形状、线宽、尺寸、卡片文案或卡片顺序；
- 减少动态效果模式继续关闭非必要动效。

## 6. “选择 JOTO”内容与布局

### 6.1 删除文案

三语言均删除 `data-about-copy` 中第二段补充正文：

英文：

> Our role is to connect strategy with field delivery: one team coordinating architecture, products, deployment and ongoing service across China and selected international locations.

中文：

> 从架构、产品到部署和持续服务，由同一团队统筹推进，覆盖中国及多个国际市场。

波斯语：

> نقش ما پیوند دادن راهبرد با اجرای میدانی است؛ یک تیم واحد، معماری، محصولات، استقرار و خدمات مستمر را در چین و بازارهای بین‌المللی منتخب هماهنگ می‌کند.

标题和第一段公司介绍保持不变。

### 6.2 统计卡布局

右侧四张统计卡由桌面端纵向四排改为 `2 × 2`：

- `2010 / 创立于上海`；
- `5 / 解决方案领域`；
- `多厂商 / 一体化交付模式`；
- `全生命周期 / 规划、部署与运营`。

桌面端：

- 左右内容区调整为 `6 / 6` 的平衡比例；
- 左侧文案与右侧统计网格顶部对齐；
- 四张卡等高；
- 统计值保持单行，并允许英文和波斯语使用响应式字号避免溢出。

平板端：

- `768px` 至 `1023px` 时统计卡保持 `2 × 2`；
- 统计网格整体落到标题和第一段正文下方。

手机端：

- 小于 `480px` 时改为单列；
- 不产生横向溢出；
- 波斯语使用 RTL 镜像和右侧起始线。

## 7. 首页“联系 JOTO”表单

采用已确认的 A 方案。

### 7.1 桌面布局

联系板块顶部改为与 Solution 详情页一致的双栏结构：

- 左侧：现有 eyebrow、标题和说明；
- 右侧：深色联系表单；
- 下方：保留现有邮箱、上海电话、服务热线和返回顶部四个入口。

双栏采用 `5 / 7` 的比例。表单顶部与左侧标题内容区对齐，四个快捷入口继续使用现有绿色板块视觉。

### 7.2 表单内容

表单复用详情页现有字段、文案、验证和状态：

- 姓名，必填；
- 公司，必填；
- 工作邮箱，必填；
- 电话 / 微信，选填；
- 项目问题描述，必填；
- 隐藏 honeypot；
- 提交按钮；
- 提交中、成功、失败及邮件回退状态。

请求继续使用：

```http
POST /api/contact
Content-Type: application/json
```

载荷保持：

```json
{
  "name": "",
  "company": "",
  "email": "",
  "phoneOrWechat": "",
  "message": "",
  "website": ""
}
```

### 7.3 响应式和方向

- `1024px` 及以上：左文案、右表单，快捷入口在下方四列；
- `640px` 至 `1023px`：文案和表单纵向排列，快捷入口两列；
- 小于 `640px`：文案、表单、快捷入口依次纵向排列，快捷入口单列；
- 波斯语镜像双栏和按钮方向；
- 邮箱输入始终保持 LTR；
- 表单提交按钮保持单行并在表单底部居中。

## 8. 技术方案

### 8.1 可选方案

1. 直接修改压缩后的 React 主 JavaScript：能控制原始组件，但风险高、难以审查和维护。
2. 扩展现有渐进增强资源，并增加首页专用精修资源：修改边界清晰、可回退、最符合当前维护方式。
3. 重建缺失的 React/Vite 源工程：长期最理想，但明显超出本次页面精修范围。

采用方案 2。

### 8.2 资源职责

- `assets/solution-card-carousel.js`：增加一次性轻推回位逻辑和用户操作取消逻辑；
- `assets/solution-card-carousel.css`：补充动效状态与减少动态效果规则；
- `assets/contact-form-sections.js`：将详情页表单渲染能力复用于首页 `#contact`；
- `assets/contact-form-sections.css`：调整 Hero 自适应按钮与首页联系表单双栏布局；
- `assets/index-e49ffBFL.css`：共享页头两个 `96 × 36px` 控件，以及纯绿色服务图标和“选择 JOTO”统计网格；
- 三语言首页 HTML：仅在新增资源确有必要时接入；优先复用已经加载的资源；
- 验证脚本：锁定三语言文案删除、按钮尺寸、动效守卫、表单和 RTL 合约。

所有 DOM 增强必须幂等。脚本未加载或执行失败时，现有首页内容和联系入口仍可使用。
