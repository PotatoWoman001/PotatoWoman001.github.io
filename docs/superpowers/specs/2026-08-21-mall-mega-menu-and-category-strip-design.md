# Mall 大菜单与连续分类带设计

## 目标

让顶部“商城”导航与“解决方案”使用一致的桌面大菜单模式，用户可从五大业务分类或其子分类直接进入 Mall 筛选结果。同时修正 Mall 页面内“更多分类”的视觉断裂，让它以同规格胶囊紧接主分类按钮，但展开菜单仍不被水平滚动容器裁切。

## 业务分类口径

顶部商城大菜单固定使用与解决方案一致的五大业务分类：

1. 网络
2. 安全
3. 服务器与存储
4. 协作通信
5. 物理安防

这五个中文值同时是 Mall 目录的稳定筛选键。菜单在三种语言中显示本地化标题，但 URL 的 `category` 参数保留原始中文筛选值，例如：

```text
/zh/mall/?category=网络
/mall/?category=网络
/fa/mall/?category=网络
```

这避免了展示翻译与目录真实值不一致导致的空结果。

## 桌面顶部商城大菜单

“商城”导航被增强为文字链接和独立箭头按钮的组合控件：

- 点击“商城”文字继续进入当前语言的 Mall 首页。
- 悬停组合控件、键盘焦点进入或点击箭头时打开大菜单。
- 移出整个导航项与菜单区域后延迟短暂关闭，避免指针穿过间隙时闪烁。
- `Escape` 关闭菜单并把焦点返回箭头；点击页面其他位置关闭菜单。
- 箭头按钮使用 `aria-expanded` 和 `aria-controls`，菜单容器使用可读的导航标签，不伪装为应用程序 `menu` 角色。

面板在桌面使用与解决方案大菜单一致的深色视觉语言、顶部导航下方定位和五列结构。每列包含：

- 一个可点击的本地化业务分类标题，直达对应 `category` 筛选。
- 从 `catalog-index.json` 动态汇总的最多 5 个热门二级分类链接，按有效商品数降序、同数量按名称排序。

二级分类从商品 `category_path` 中提取：找到五大分类值所在位置后，取其后第一个非空段作为子分类。若某业务分类暂无二级数据，列标题仍保留且可点击，不添加虚构内容。

数据加载失败时，导航文字和五个顶级分类仍然可用；只隐藏动态子分类，不在顶部导航显示错误面板。

## 移动导航

手机和平板的抽屉导航不显示桌面巨型面板。“商城”保留首页链接，并提供一个可展开的五分类列表；每项直达筛选结果。移动端不显示动态二级分类，避免抽屉过长。展开按钮保留 `aria-expanded`，在导航抽屉关闭或路由变化后重置。

## Mall 页面内连续分类带

主分类按钮和“更多分类”必须在视觉上组成同一条连续分类带：

- “更多分类”紧接最后一个主分类，中间只保留与其他胶囊相同的 `10px` 间隔，不使用右侧独立列。
- 触发器改为与分类按钮一致的 `40px` 高圆角胶囊、边框、字号和悬停状态，保留小箭头。
- 分类带可水平滚动，但“更多分类”的展开面板由一个不受滚动容器裁切的独立浮层承载。
- 浮层通过触发器的实时视口坐标定位，在窗口缩放、滚动或 RTL 页面中都保持与触发器对齐且不越出视口。
- 展开浮层不改变分类带或结果区域的文档流位置。

现有分类选中、URL 同步、键盘操作、点击外部关闭和网格/列表状态保持不变。

## 组件边界

- `assets/mall-navigation-and-page.js` 负责识别桌面/移动导航中注入的 Mall 链接、创建五分类菜单、加载目录索引、生成直达链接和管理交互。
- 新增的 Mall 导航样式使用独立 CSS 资产，不直接修改已编译的主站 CSS bundle。
- `assets/mall-catalog-pages.js` 继续负责页面内分类选择，但将“更多分类”的浮层从裁切轨道中脱离并按视口定位。
- `assets/mall-data-client.js` 保持目录读取和查询接口；商城大菜单可复用 `loadCatalogIndex()`，不复制第二套 fetch 规则。

## 验收标准

1. 桌面“商城”文字可进入 Mall 首页，箭头、悬停和键盘可打开五列大菜单。
2. 五个顶级分类链接和实际子分类链接进入正确的当前语言 Mall URL，页面显示非空筛选结果。
3. 三语桌面菜单保持正确 LTR/RTL 布局，无水平页面溢出，不遮挡导航可用性。
4. 手机导航可展开五个顶级分类，不渲染桌面巨型面板。
5. Mall 页面内“更多分类”和左侧类型胶囊连续排列，触发器视觉尺寸一致。
6. 打开页内更多分类后菜单不被裁切、不越出视口、结果区域垂直位置变化不超过 `1px`。
7. 目录数据失败时顶部 Mall 首页链接和五个顶级分类仍可用。
8. 现有 Mall 高密度列表、网格、搜索、分页、详情和三语路由回归全部通过。

## 发布边界

新增的顶部商城导航 CSS、Mall 导航 JavaScript、页内分类 JavaScript/CSS 及九个 Mall 页面必须使用同一新缓存版本。发布必须使用经过静态契约与真实浏览器验证的精确 Git 提交，并隔离工作区其他改动。未获得用户明确生产授权时不切换线上发布。
