# JOTO Global 网站修改规则

本文档用于约束 JOTO Global 网站后续的设计与页面修改。只有经过确认的规则才可写入本文档，并作为后续网页更新和验收的依据。

## 已确认规则

### 1. 英文字体统一使用 Poppins

- 全网站所有普通英文文本统一使用 `Poppins`。
- 适用范围包括但不限于：导航、标题、正文、说明文字、标签、卡片、按钮、表单、页脚以及所有页面和详情页中的英文界面文字。
- `Poppins` 使用网站现有的本地字体文件，按内容层级使用已有的 `400`、`500`、`600`、`700`、`800` 字重。
- 普通英文文本不得继续以 `Inter`、`Plus Jakarta Sans` 或其他无衬线字体作为最终显示字体。
- 现有等宽字体英文标签、编号说明和技术型装饰文字也统一改用 `Poppins`；等宽字体不属于本规则的保留例外。
- 例外：绿色衬线体文字，以及具有打字、闪现或闪回效果的绿色衬线体片段，继续保留现有衬线字体与动画表现，不改为 `Poppins`。
- 字体调整不得改变既有文本内容、语义、字号层级、颜色和动画节奏；本规则只约束英文字体家族。

### 1.1 多语言字体栈与品牌衬线例外

- 英文及所有页面中保留的普通拉丁字母文本使用 `Poppins, sans-serif`。
- 中文页面使用 `Poppins, "PingFang SC", "Microsoft YaHei", sans-serif`；其中英文片段优先命中 `Poppins`，中文字形由中文系统字体自然回退。
- 波斯语页面使用 `Poppins, Vazirmatn, sans-serif`；其中英文片段优先命中 `Poppins`，波斯文字形由 `Vazirmatn` 回退。
- 唯一保留 `Instrument Serif` 的内容是绿色斜体品牌词，例如首页 Hero 中的 `IT`、`Network`、`Collaboration`。普通标题、正文、导航、按钮、表单和页脚不得使用该字体。

### 1.2 全站字体层级

全站采用五级标题与五级正文/辅助文字。桌面指视口宽度不小于 `1280px`，平板为 `768–1279px`，手机为不大于 `767px`。

| 层级 | 用途 | 桌面 | 平板 | 手机 | 字重 |
| --- | --- | --- | --- | --- | --- |
| T0 | 首页 Hero 与解决方案类别主标题 | `96px / 0.92` | `68px / 0.92` | `48px / 0.92` | 600 |
| T1 | 普通页面与详情页主标题 | `72px / 1` | `56px / 1` | `40px / 1` | 600 |
| T2 | 主要板块标题 | `56px / 1.08` | `44px / 1.08` | `34px / 1.08` | 500 |
| T3 | 大卡片与专题标题 | `28px / 1.2` | `26px / 1.2` | `22px / 1.2` | 500 |
| T4 | 小卡片与表单标题 | `20px / 1.3` | `20px / 1.3` | `18px / 1.3` | 500 |
| B1 | Hero 摘要与关键导语 | `18px / 30px` | `18px / 30px` | `17px / 28px` | 400 |
| B2 | 普通正文 | `16px / 28px` | `16px / 28px` | `16px / 27px` | 400 |
| B3 | 卡片说明与次级控制文字 | `14px / 22px` | 同左 | 同左 | 400–600 |

- 普通可读文字不得小于 `11px`；只有不承担信息阅读任务的纯装饰遥测元素可以更小。
- 桌面导航使用 `14px / 500`，移动菜单使用 `16px / 500`。
- 按钮与操作控件使用 `14px / 600`，表单输入使用 `14px`，页脚链接使用 `14px`，页脚辅助文字使用 `12px / 20px`。

### 2. 文本框边界与语言方向统一对齐

- 每个内容区域必须设置明确且统一的左右内容边界。
- 同一内容区域中的标题、正文、说明文字和操作按钮共用一致的起始基准线。
- 英文和中文内容从左侧基准线开始，整体左对齐。
- 波斯语内容采用镜像规则，从右侧基准线开始，整体右对齐。
- 标题可以使用比正文更宽的文本框；正文可以设置较窄的最大宽度，但两者必须共享相同的语言起始基准线。
- 文本必须在文本框内自然换行，不得越过内容区域的左右边界。
- 按钮区域必须与对应正文共享相同的语言起始基准线，按钮文字和图标之间保持稳定间距。
- 本规则统一的是文本框的外边界和起始基准线，不要求将每一行文字强制拉伸为两端对齐。
- 桌面、平板和手机断点均需保持上述对齐关系；响应式变化只能调整容器宽度和间距，不得破坏基准线。

### 3. 按钮采用紧凑按钮和标准 CTA 两级尺寸

- 短文案行动按钮统一采用紧凑尺寸：宽 `96px`、高 `36px`。
- 共享页头中的 Contact 按钮和语言选择器均采用紧凑尺寸：宽 `96px`、高 `36px`。
- 主要行动按钮（CTA）统一采用标准尺寸：宽 `280px`、高 `48px`。
- 手机端标准 CTA 使用 `width: 100%` 和 `max-width: 280px`，不得超出所在内容容器。
- 首页 Hero 的“查看解决方案”和“联系我们”是标准 CTA 固定宽度规则的已确认例外：高度保持 `48px`，同一语言内两颗按钮采用较长文案测得的同一宽度，左右内边距为 `28px`；空间不足时整颗按钮换行，按钮文字不得换行。
- 两级按钮中的文字与图标必须在按钮内部垂直居中，并保持稳定的水平间距。
- 中文、英文和波斯语按钮均采用同一套外部尺寸；波斯语按钮内部的文字与图标方向按照从右到左规则镜像排列。
- 地图定位圆点、语言选择器、菜单开关、轮播控制、表单字段及其他功能型控件不属于行动按钮，不强制套用上述两级尺寸。

### 4. 页头品牌副标题统一为全球服务定位

- 所有页面和详情页的页头品牌区域中，`JOTO` 旁边的两行副标题统一修改为：

  ```text
  Global IT
  Service Provider
  ```

- 页面必须保留以上大小写和两行结构，不得自动转换为全大写。
- 中文、英文和波斯语页面共用同一英文品牌副标题，不进行翻译。
- 本规则只修改品牌副标题；`JOTO` 主标识和 `JOTO TECH` 品牌名称在正文、SEO 信息及法律实体名称中的使用不受影响。
